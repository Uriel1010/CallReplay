# CallReplay 2.0.0 — Preview 1

First public CallReplay preview, an independent fork of
[ShizuCallRecorder](https://github.com/kitsumed/ShizuCallRecorder) by kitsumed (Med).

## Features

- Call logs open by default, with caller details, date groups and incoming/outgoing filters.
- Search by name, phone number or filename.
- Inline play, pause and seeking; share recordings through Android's Sharesheet.
- Browse older recordings in the selected folder.
- Hebrew interface, RTL layouts, light/dark themes and adaptive navigation.

## Download

Install **CallReplay-2.0.0-preview.1-debug.apk**. This is the exact debug-signed APK installed
and tested on a physical CPH2747, not a production-signed build. Its Android version metadata
is `2.0.0` (version code `20`), package `io.github.uriel1010.callreplay`.

SHA-256:

```text
950a244a2c6816ef15dfba4f37c643535260305842ca70d2787217be1d4139fb
```

New recordings require Shizuku, permissions and a recording folder. Android 11+ is the
installation minimum; capture compatibility depends on the device and Android version.
The call log lists recorded calls. Older recordings without caller metadata use filenames.

## Validation

All **17 instrumentation tests passed** on the distributed APK. Checks cover default routing,
playback, seeking, persistence, search, filtering, share intents, Hebrew/RTL rendering,
landscape and large text. Lint: zero errors, 117 warnings. Tests use synthetic caller details
and audio; call-capture compatibility on other devices has not been established by these tests.

For Hebrew: **Settings → Language → עברית**, or follow the phone's system language.
The original nontranslatable legal disclaimer and technical identifiers remain in their
source language.
