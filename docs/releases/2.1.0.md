# CallReplay 2.1.0

First production-signed CallReplay release. Package:
`io.github.uriel1010.callreplay`; version code `22`; Android 11 or newer.

## Included

- Hebrew and English interface, right-to-left support, light and dark modes.
- Recorded-call log opens by default, with search, call-direction filters,
  inline playback and recording sharing.
- Full recording player with seeking, 10-second skips, speed, mute, share,
  file information and confirmed deletion.
- Task-focused setup, recording exclusions, filename templates, folder selection,
  library licenses and original-project attribution.
- **Settings → About → Check for updates**: stable GitHub release checking,
  optional daily foreground checks, optional previews, explicit downloads with
  progress/cancel/retry, verified APKs and Android installation confirmation.
- The same production APK can be tracked in Obtainium by adding
  `https://github.com/Uriel1010/CallReplay`.

## Signing and migration

This APK is a non-debuggable, optimized release signed with CallReplay's dedicated
RSA-4096 production key. It includes a signing lineage from the original
CallReplay debug-preview certificate. Android 11+ can use this proof for an
in-place upgrade while preserving application data. Do not uninstall the preview
to bypass an installation error; report the error instead.

Production signing certificate SHA-256:
`33ec7da8dec0b3ba3797cad79ea1d9984a96e5d4f25fe4d8c604bbf105d4b6b4`.

The APK's SHA-256 is in the attached `SHA256SUMS`. `callreplay-update.json`
describes the exact APK used by the in-app updater. Matching GPL source and
build/signing instructions are available in this tag and `docs/updates.md`.

## Verification and limits

The included reference UI previously passed 33 instrumentation tests on a
physical CPH2747 using synthetic recordings and contacts. The production updater
adds host tests for release URL restrictions, exact download integrity and
cancellation, plus device-test fixtures for Hebrew update states and actions.

This release's build and signature checks are recorded in the repository's
verification notes. The phone was offline in ADB during release preparation:
new device tests, rendered updater checks, and actual in-place migration remain
pending. Signature verification alone does not establish device execution or
call-capture compatibility. Recording support still depends on Android, device
firmware, audio source and Shizuku. Test on your device before relying on it.

Automatic update checks are initially off. Checks contact GitHub and do not send
caller details or recordings. Downloads and installation require your action.
See `docs/updates.md` for privacy and update behavior.
