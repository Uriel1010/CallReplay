# CallReplay 2.1.1

Fixes recording attachments that other apps could not reliably download or play.
Package `io.github.uriel1010.callreplay`; version code `23`; Android 11 or newer.

- Sharing now prepares actual AAC-LC audio in an MP4 container with a `.m4a`
  filename and `audio/mp4` MIME type. Opus, AMR and HE-AAC recordings are converted
  locally; compatible AAC-LC recordings are remuxed without re-encoding.
- The receiving app gets a read-only URI for a completed, app-owned attachment,
  independent of access to the original recording folder.
- Original recordings remain unchanged. Stereo conversion preserves both channels.
- A preparation notice supports cancellation and reports export failures.
- Completed exports support delayed imports. Exports older than seven days are
  pruned on the next share and are excluded from Android backup and device transfer.

Previously sent messages are unchanged: share the recording again after updating.
WhatsApp accepts the exported MIME type on the tested phone. Synthetic media tests
verify conversion, duration, stereo audio, packet-preserving remux, cancellation,
failure cleanup and complete attachment reads from another app UID. This does not
establish WhatsApp delivery between two accounts.

This is a production release signed with the existing CallReplay production key.
Install over your existing copy; do not uninstall. The attached checksum and update
manifest identify the exact APK. Matching source is available through this tag.
