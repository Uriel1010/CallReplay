# CallReplay

Native Android call recorder and local recording library. Main tasks: find a recorded call,
listen, share, and configure reliable capture using Shizuku. Hebrew is a primary locale;
English and existing translations remain supported. Audio stays in the selected SAF folder.
No accounts, upload, transcription, or fabricated caller metadata.
